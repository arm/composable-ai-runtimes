Cairn Modules are the core runtime building blocks of Cairn SDK. Each module provides focused capabilities for your application, such as camera management, AI inference, or cross-module messaging. Modules run in separate containers and expose stable APIs and events through the Cairn Client Library.

This section describes each module's purpose and capabilities in detail.

## How to use this section

Use the left nav to jump into each module page for capabilities and quick-start examples.

If you're looking for an architectural understanding of modules and their interfaces, see [System Components: Cairn Modules](/architecture/components/cairn-modules).

You can also jump to the [API Reference](/api) for detailed endpoint contracts and schemas for each module.
