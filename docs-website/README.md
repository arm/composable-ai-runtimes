# Website

This website is built using [Docusaurus](https://docusaurus.io/), a modern static website generator.

## Directory Overview

```
docs-website/
├─ docs/                Docs content (routed from site root)
│  ├─ tutorials/        Tutorials section
│  ├─ api/              API section
│  └─ intro.md          Top-level intro doc
├─ src/
│  ├─ pages/            Landing pages (index.md)
│  ├─ components/       Custom React components
│  └─ css/custom.css    Global theme overrides
├─ static/              Static assets served as /
├─ docusaurus.config.ts Site config (navbar, theme, routing)
├─ sidebars.ts          Sidebar definitions (autogenerated)
└─ build/               Production output (generated)
```

## Content Authoring

- Add docs in `docs/`.
- Sidebar structure is autogenerated from folder layout in `sidebars.ts`.
- Ordering comes from frontmatter `sidebar_position` or `_category_.json`.

## Config and UI

- `docusaurus.config.ts` for site metadata, theme, and routing.
- `src/pages/` for custom routes, `src/components/` for shared UI.
- `src/css/custom.css` for styling overrides.

## Installation

```bash
pnpm install
```

## Local Development

```bash
pnpm start
```

This command starts a local development server and opens up a browser window. Most changes are reflected live without having to restart the server.

## Build

```bash
pnpm run build
```

This command generates static content into the `build` directory and can be served using any static contents hosting service.
